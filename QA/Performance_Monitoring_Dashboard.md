# Performance Monitoring Dashboard

## Dashboard Name
Example: OMS_Performance_Metrics

## Key Metrics
- Response time (P95, P99)
- Throughput (requests/sec)
- Error rate (%)
- CPU utilization (%)
- Memory utilization (%)

## Alerts
- Response time > threshold
- Error rate > threshold
- CPU > threshold

## Data Source
- APM tool / Cloud monitoring
